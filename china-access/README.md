# Acceder a China desde el extranjero · Todo lo que necesita una IP china

Cuando estás fuera de China, muchos servicios chinos te rechazan porque tu IP no es de China continental: vídeo, música, trámites oficiales, banca, compra de billetes, juegos. Hay un artículo para cada caso, que explica con claridad **por qué te bloquean, cómo solucionarlo y qué otras trampas hay**.

**El artículo más consultado: [Desbloquear webs de vídeo chinas desde el extranjero con un router](../router/06-unlock-chinese-video-with-router.md)**: la tele, el decodificador y todos los dispositivos de casa se configuran una sola vez, y basta con conectarse al wifi para ver iQIYI, Tencent Video y Yangshipin.
