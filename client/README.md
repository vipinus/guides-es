# Guías de clientes · Instalación y configuración

Instrucciones paso a paso para **instalar y conectar** cada método de acceso: Cisco AnyConnect, Hiddify, la extensión de proxy web, OpenVPN y la red privada (Tailscale). También verás qué hacer cuando iOS no te deja instalar una app, cómo instalar Telegram y Discord, cómo configurar muchos dispositivos de una vez y qué hacer cuando programas como Dropbox te piden un proxy. Para elegir método, consulta [Qué método de conexión conviene en cada situación](../network/02-choose-your-connection-method.md); si ya lo tienes instalado pero no conecta, ve a [Solución de problemas](../troubleshooting/).
